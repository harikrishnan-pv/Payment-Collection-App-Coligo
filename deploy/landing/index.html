Coligo — Payment Collection App

REST API for personal-loan EMI payments. The React Native (Expo) mobile app talks to this server via /api.

Endpoints

GET /api/customersLoan details of all customers.
GET /api/customers/:account_numberLoan details for one account.
POST /api/paymentsRecord an EMI payment — body {"accountNumber","amount"}. One EMI per account per calendar month; a repeat gets 409 EMI_ALREADY_PAID.
GET /api/payments/:account_numberPayment history for an account, newest first.
POST /api/demo/resetReset demo data — wipes payments and re-seeds the 12 demo accounts, so every account can pay again.
GET /api/healthLiveness probe.

The Express service also serves the exact same handlers at the root paths (/customers, /payments).

Try it

curl http://HOST/api/customers

curl -X POST http://HOST/api/payments \
  -H "Content-Type: application/json" \
  -d '{"accountNumber":"ACC-100234","amount":12480.50}'

curl http://HOST/api/payments/ACC-100234

# hit EMI_ALREADY_PAID? reset the demo data:
curl -X POST http://HOST/api/demo/reset
